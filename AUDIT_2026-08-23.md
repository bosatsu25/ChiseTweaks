# 2026-08-23 UI / CI Quality Audit

## Scope

- main settings UI
- released highlight controls
- unreleased Visual Filter controls
- CI / Official Release toolchain
- retained-scope JaCoCo / PIT gates
- version and artifact identity

## Findings fixed in this pass

### Existing defects

1. Highlight header rendered an obsolete bulk ON/OFF control even though the prerelease policy permanently disabled that control.
2. Visual Filter duplicated a Settings button on both block and entity rows instead of using one section-level entry point.
3. Main screen row interactivity and action interactivity shared one boolean, so a toggle/header could not stay visually available while its secondary action remained release-gated.
4. The screenshot can show an older loaded runtime version independently of source because the title reads the version from Fabric Loader metadata. The new artifact therefore uses a new patch version so stale Prism JARs are visually distinguishable.

### Latent defects / regression risks

1. `BOOLEAN_ACTION` and the secondary row-button slot existed only for the duplicated Visual Filter actions and could reintroduce two-control layout regressions.
2. Worksite highlight profile policy and settings UI policy/layout were outside the retained 96% JaCoCo/PIT scope.
3. CI depended on mutable action tags and had no self-check that the actual Java/Python/Gradle runtime matched the declared contract.
4. Python and Gradle CI runtimes were behind the current stable supported line used by this project.
5. PIT was executed after a failed JUnit run even though mutation testing requires a green base suite, creating duplicate failure noise.

### New-regression controls

- one right-aligned Settings action per configurable main section
- no Highlight bulk implementation in production UI/controller/layout
- Visual Filter main rows are plain toggles
- Material / Fine Thread / Hidden target migrations remain covered
- UI layout and prerelease policy are mutation-tested
- CI toolchain versions and pinned Action SHAs are repository-audited

## Runtime acceptance still requiring Prism

Automated CI cannot reproduce the target Windows display-driver/GPU path. After the new JAR is installed, verify the visible version, main settings layout, settings navigation, and representative feature frametime in Prism.
