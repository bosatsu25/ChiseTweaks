# ChiseTweaks Versioning Policy

ChiseTweaks uses Semantic Versioning for the product version and keeps Minecraft compatibility in SemVer build metadata.

## Format

`MAJOR.MINOR.PATCH+mc<Minecraft version>`

Example: `0.8.0+mc26.1.2`

The SemVer core is `0.8.0`. The `+mc26.1.2` suffix identifies the Minecraft compatibility target and does not change SemVer precedence.

## When to increment

- **PATCH** (`0.8.0` -> `0.8.1`): bug fixes, performance tuning, QA/CI hardening, documentation, or UI polish that does not add a user-facing capability or intentionally break a contract.
- **MINOR** (`0.7.7` -> `0.8.0`): backward-compatible user-facing functionality, a new feature/toggle/analyzer, or a substantial new workflow capability. Ancient Debris Analyzer is therefore released as `0.8.0`.
- **MAJOR** (`0.x.y` -> `1.0.0`, then `1.x.y` -> `2.0.0`): an intentional incompatible configuration/runtime/API contract, removal requiring migration, or the first declared stable 1.0 contract.

Although SemVer permits broad changes before 1.0, ChiseTweaks intentionally follows these rules during `0.x` development so release meaning stays predictable.

## Release rules

1. Every official release must increase the SemVer core. Reusing the same version for a different main commit is forbidden.
2. Normal CI never creates a tag or GitHub Release.
3. Only the manually started **Official Release** workflow creates the version tag and GitHub Release.
4. The only user-uploaded Release asset is the installable runtime JAR.
5. `-sources.jar`, QA JSON, checksums, reports, ZIP files, and tarballs are never uploaded as ChiseTweaks Release assets.
6. GitHub automatically exposes source-code `.zip` and `.tar.gz` links for every Git tag/Release. Those are generated by GitHub itself and cannot be disabled by the ChiseTweaks workflow; they are not mod artifacts and must not be installed in Prism Launcher.

## Release checklist

- Update `mod_version` in `gradle.properties` according to this policy.
- Merge through the normal CI quality gate.
- Smoke-test the exact main commit in Prism Launcher.
- Start **Official Release** from `main`, select the intended `patch` / `minor` / `major` release type, and confirm the smoke test.
- Verify the Release has one uploaded asset: `chise-tweaks-<version>+mc<version>.jar`.
